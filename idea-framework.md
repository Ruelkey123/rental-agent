# Idea Framework

Score each 1–3. Max 18.

| # | Criterion | Question to ask |
|---|-----------|-----------------|
| 1 | Lived it | Can I name a specific person + moment when this hurt? |
| 2 | One sharp job | Can I say v1 in one sentence: "X does Y for Z"? |
| 3 | ~3 hrs to build | No auth/payments/marketplace/missing data? |
| 4 | 60-second demo | No sign-up; "oh, that's useful" within a minute? |
| 5 | Real Vercel surface | Uses AI SDK/Gateway, Blob, Marketplace DB, cron, etc. naturally? |
| 6 | Interesting cuts | Obvious features I'll deliberately leave out? |

**Kill if:** generic "AI chatbot for X", reuses an existing project, needs paid API or approvals.
